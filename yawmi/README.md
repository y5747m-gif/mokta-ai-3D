# يومي | YAWMI — المنظم الذكي للطالب 🌅📚

> **YAWMI — Smart Student Planner** تطبيق إنتاجي كامل مصمَّم لطالب **الصف الثاني الثانوي الأزهري — القسم الأدبي**:
> جدول أسبوعي تفاعلي (السبت → الجمعة)، منبهات وتذكيرات ذكية، مؤقت مذاكرة، واجبات ومراجعة متباعدة،
> عادات يومية، روتين نوم، ومساعد تخطيط يعمل **دون إنترنت ودون أي API خارجي**.

## ⚡ التشغيل السريع

لا يحتاج المشروع إلى أي `npm install` أو خطوة بناء — ملفات HTML/CSS/JS جاهزة.

```bash
cd yawmi
node serve.mjs                 # الخادم المدمج → http://localhost:8080
# أو أي خادم ثابت آخر:
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080` في المتصفح (يفضَّل Chrome على أندرويد).

### الاختبارات

```bash
cd yawmi
npm test                # أو: node tests/run-tests.mjs
```

‏101 اختبارًا لمحرك الجدول والمنبهات والوقت والتنسيق العربي والمساعد والنسخ الاحتياطية.

## 📱 التثبيت كتطبيق (PWA)

1. افتح الرابط في **Chrome على أندرويد** (أو Edge/Safari على الحاسب).
2. من القائمة (⋮) اختر **«إضافة إلى الشاشة الرئيسية»** / **Install app**.
3. سيظهر تطبيق «يومي» بأيقونته الخاصة ويعمل بنافذة مستقلة.
4. بعد أول فتح، يعمل التطبيق **كاملًا دون إنترنت** (Service Worker + كاش للملفات).

### إشعارات أندرويد

- فعّل إذن الإشعارات عند أول تفعيل للمنبه (سيشرح التطبيق سبب الطلب).
- على أندرويد 13+ امنح صلاحية **الإشعارات** من إعدادات التطبيق.
- أبقِ التطبيق في قائمة التطبيقات الأخيرة، وعطّل «تحسين البطارية» له إن أردت أعلى موثوقية ممكنة.

## ⏰ نظام المنبهات — القدرة والحدود (بصراحة كاملة)

| الحالة | الاعتمادية |
|---|---|
| التطبيق مفتوح (أو في الخلفية القريبة) | ✅ موثوق تمامًا — صوت + اهتزاز + طبقة منبه بملء الشاشة |
| التطبيق مثبت + إذن الإشعارات مفعّل | ✅ جيد — إشعارات النظام تصل في معظم الحالات |
| المتصفح مغلق تمامًا / وضع توفير الطاقة | ⚠️ قد تتأخر أو تضيع إشعارات الخلفية — **هذا قيد في متصفحات الويب نفسه** |
| منبه الاستيقاظ المهم | ✅ ضعف الأمان: اترك التطبيق مفتوحًا مع تفعيل «إبقاء الشاشة مضاءة» (Wake Lock)، أو استخدم منبه الجهاز كاحتياط |

**تطبيق ويب تقدمي لا يمكنه ضمان دقة منبه المنبّه الأصلي للنظام (AlarmManager).**
إذا كنت تحتاج منبه استيقاظ بدقية نظام كاملة، فهذا يتطلب تطبيق أندرويد أصليًا.
هذا المشروع يسلّم أقوى ما يمكن عمله بصدق داخل منصة الويب: مؤقّت داخلي دقيق،
إشعارات Service Worker، استعادة المنبهات الفائتة عند الإقلاع، تأجيل 5/10/15،
سجل كامل (انطلق/أُوقف/فات/تم)، ومنع تكرار التذكيرات بمفاتيح موحّدة.

## 🗄️ التخزين والموثوقية

- **IndexedDB** (`yawmi-db`) مع ترحيلات آمنة بإصدارات — لا فقدان صامت للبيانات.
- كل تعديل يُحفظ تلقائيًا (write-through).
- معرّفات فريدة لكل فعالية/منبه/مهمة + مفاتيح تذكيرات موحّدة تمنع التكرار.
- **تصدير/استيراد** نسخة احتياطية كاملة (JSON) من «الإعدادات».
- استعادة الجدول الافتراضي **بتأكيد صريح فقط** — لا تُمس بياناتك دون إذن.
- يعمل دون حسابات ولا اشتراكات ولا خوادم — البيانات كلها على جهازك.

## 🗓️ الجدول الأسبوعي

محمَّل مسبقًا بمواعيد الطالب الأصلية (السبت → الجمعة) كما هي حرفيًا:

- الدروس: شرعي، إنجليزية، فلسفة (السبت)، فرنسية (الأحد)، جغرافيا (الاثنين)، شرعي (الثلاثاء)، تاريخ (الأربعاء)، عربي (الجمعة).
- السبت: **الإنجليزية تنتهي مع بداية الفلسفة** — يُعرض كجدول متصل، مع إمكانية ضبط وقت التنقل.
- الخميس: **الدرس الشرعي الاختياري معطّل افتراضيًا** حتى يؤكده الطالب، ويُعرض وقت بديل تلقائيًا (مذاكرة أو راحة).
- كشف التعارضات: أي تداخل يُعلَّم بالأحمر ويُطلب الحل من الطالب — **لا يُغيَّر أي موعد بصمت أبدًا**.
- أوقات السفر قابلة للتعديل لكل درس (تذكير السفر يُحسب منها).

## 🧠 التذكيرات الذكية للدروس

‏60 / 30 / 15 دقيقة قبل الدرس + عند البدء + تذكير السفر (قابل للتهيئة).
إذا كان هناك درسان متتاليان: تُسقط التذكيرات المتناقضة داخل الدرس السابق،
ويحل محلها تذكير واحد واضح «الدرس القادم متصل».

## 🤖 المساعد الذكي

يعمل محليًا (بدون أي مفاتيح API — ولا يوجد أي كود يخاطب خدمات خارجية):

- «ماذاذاذا أذاكر اليوم؟» — خطة مبنية على جدولك الفعلي
- «فاتتني المذاكرة — رتب يومي» — إعادة ترتيب تحافظ على الدروس المؤكدة والنوم
- «كم وقت فراغ لدي اليوم؟»
- «ذكّرني بمراجعة الفلسفة غدًا»
- «أعِد لي خطة مراجعة للتاريخ» / «لدي امتحان أسبوع قادم»
- «أرني المهام غير المنجزة» / «اجعل الخميس يوم تعويض»

كل إجراء يمس الجدول **يطلب موافقتك أولًا**.

## 🤖 بناء APK (اختياري — لم يُنفَّذ في هذا المستودع)

هذا المستودع يسلّم **PWA عاملًا**، ولم يُبنَّ أي APK هنا (لا يُدَّعى ذلك).
إذا أردت لاحقًا تغليفه كتطبيق أندرويد بـ WebView/TWA، فهذه خطوات معروفة:

1. انشر الـ PWA على HTTPS (مثل Vercel — يدعمها هذا المستودع بملف `vercel.json` موجود بالفعل).
2. استخدم [Bubblewrap CLI](https://github.com/GoogleChromeLabs/bubblewrap) لإنشاء مشروع TWA:
   `bubblewrap init --manifest https://your-domain/manifest.webmanifest`
3. `bubblewrap build` → يُنتج APK/AAB موقّعًا بـ Android Studio المضمّنة.
4. **تنبيه:** حتى مع TWA، منبهات الخلفية تبقى محدودة بنظام أندرويد للويب؛
   للحصول على `AlarmManager` حقيقي يلزم تطبيق أصلي (Kotlin/Flutter/React Native مع مجلد `android/`).

## 🔒 الخصوصية

- لا حسابات، لا تتبع، لا إعلانات، لا خوادم.
